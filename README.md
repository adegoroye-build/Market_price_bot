# Trading Assistant Bot

A Telegram bot that tracks forex and crypto prices and monitors trades in real-time.

## Features
- Live price check (EURUSD, USDJPY, BTCUSD)
- Trade tracking (Entry, TP, SL)
- Profit/Loss calculation
- 24/7 cloud deployment (Render)

## How to use
Send commands in Telegram:
- EURUSD
- BUY EURUSD 1.0850 TP 1.0900 SL 1.0800

## Tech Stack
Python, Telegram Bot API, Render, Alpha Vantage
